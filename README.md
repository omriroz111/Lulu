# Lulu — אתר המסעדה והבר

אתר סטטי, חמישה עמודים, עברית מלאה (RTL). השם **Lulu** הוא המילה היחידה באנגלית באתר.

```
index.html      בית
menu.html       תפריט
gallery.html    גלריה
about.html      אודות
location.html   מיקום והזמנת מקום
404.html        עמוד "לא נמצא" (מחובר ב־.htaccess וב־nginx-headers.conf)
robots.txt      מאפשר סריקה; sitemap.xml חסר כי הוא דורש את כתובת הדומיין
assets/css/     גיליון סגנון אחד
assets/js/      main.js — ניווט, אנימציות, לייטבוקס
photos/         התמונות של המקום
```

## התפריט

התפריט אמיתי, מהקובץ שהבעלים שלח (`תפריטלולו.txt`). הנתונים נמצאים בראש
`tools/build_menu.py`; לשינוי מחיר או מנה עורכים שם ומריצים
`python tools/build_menu.py` — הסקריפט מחליף את בלוק התפריט ב־`menu.html`.

## הפעלה

אין שלב בנייה ואין תלויות. פותחים את `index.html` בדפדפן, או מעלים את התיקייה
כמו שהיא לכל שירות אחסון (Netlify / Vercel / cPanel) בגרירה אחת.

## מה עוד צריך להשלים

### 1. תוכן שהמצאתי — צריך אישור של הבעלים

| איפה | מה |
|---|---|
| `location.html` | מספר הטלפון `08-000-0000` — מספר מומצא, חייב להתחלף |

הפסקה הראשונה ב"אודות" ובעמוד הבית, הכתובת והשעות, ושתי הפסקאות בהמשך
עמוד "אודות" — כל אלה כבר טקסט אמיתי שהבעלים שלח.

### 2. קישורים חיצוניים

* **הזמנת מקום** ב־`location.html` מוביל ל־Ontopo
  (`ontopo.com/he/il/page/60793780`) בחלון חדש. כפתורי "להזמנת מקום" בשאר
  העמודים מובילים לעמוד המיקום, ומשם ל־Ontopo.
* **אינסטגרם** מחובר בכל העמודים ל־
  [instagram.com/lulu.cocktail.bar](https://www.instagram.com/lulu.cocktail.bar/).

### 3. תמונות

בתיקיית `photos/` יש שלוש תמונות אמיתיות של המקום (`bar-01/02/04`),
שהוקטנו ל־2000px ונשמרו ל־web. המקור המלא שמור ב־`photos/_original/`.

להוספת תמונות: לשים קובץ ב־`photos/`, ואז ב־`gallery.html` להעתיק בלוק
`<button class="tile ...">` ולעדכן `src` ו־`alt`.
`tile--banner` = רחבה על כל השורה, `tile--p3` = לאורך, חצי שורה.

## דברים ששווה לדעת

**הכוס והקובייה בעמוד הבית** הן רינדור תלת־ממד אחד (Blender, מנוע Cycles):
זכוכית עם שבירת אור אמיתית, משקה עם צבע ועכירות, שמשיית נייר, וקובייה
מטיח בצבע כתום שרוף עם פינות מעוגלות וצל אמיתי של הכוס. הרינדור נשמר
כתמונה אחת, `assets/img/coupe.webp`, ויושב בתוך ה־SVG של עמוד הבית בדיוק
מעל הקובייה המצוירת (שנשארה מתחת רק כגיבוי אם התמונה לא נטענת).

העמוד שיורד לאורך כל הדף (`.plinth`) לובש את אותו טקסטורת טיח,
`assets/img/plaster.webp`, באותו קנה מידה ובאותה נקודת התחלה כמו ברינדור,
ו־`finish.py` מעביר את תחתית הקובייה ברינדור בהדרגה למה שה־CSS מצייר — לכן
אין תפר.

לרינדור מחדש (למשל אחרי שינוי צבע המשקה ב־`make_glass.py`):

```
python tools/glass/make_backdrop.py backdrop.png
python tools/glass/make_tile.py .            (ואז להעתיק plaster.webp ל־assets/img)
blender -b --factory-startup --python tools/glass/make_glass.py -- backdrop.png plaster.png render.png 768 2.6
python tools/glass/finish.py render.png
```

`proof.py` מרכיב רינדור על הדמיה של הדף ו־`measure.py` מדפיס צבעים בנקודות
קבועות מול ערכי היעד — שניהם לבדיקה בלבד. הגרסה הראשונה — כוס מצוירת
ב־SVG — נראתה "צעצועית", בעיקר בגלל פרופורציות של כוס נמוכה ורחבה; קוקטייל
קופ אמיתי גבוה פי 1.5 מרוחבו.

**גופנים.** כל העברית והממשק ב־Assistant (נטען מ־Google Fonts). המילה
`Lulu` — הלוגו בתפריט העליון, הכותרת הענקית והפוטר — ב־DM Serif Display,
שמאוחסן מקומית ב־`assets/fonts/`. הגופן צומצם לתווים לטיניים והומר ל־woff2
(72KB ← 15KB), עם TTF כגיבוי. רישיון ה־OFL נמצא באותה תיקייה, כנדרש.

**תמונות סטוק שהוסרו.** בגרסה קודמת של הפרויקט היו חמש תמונות סטוק. הן הועברו
ל־`assets/img/_unused/` ואינן בשימוש:

* `dish.webp` — נושאת **סימן מים גלוי** של `GLOBALIMAGECREATION.COM` ואסור להשתמש בה.
* `wine-glass.jpg` — מציגה מותג יין אחר (Dalvina Winery).
* `table-rose.jpg` — צולמה באור יום, ומציגה בקבוק ממותג.
* `cocktail-red.jpg`, `gin-fizz.jpg` — תמונות טובות, אבל לא ידוע מה הרישיון שלהן.

מומלץ למחוק את התיקייה לפני העלאה לאוויר.

**גרסה קודמת של האתר** (עיצוב אחר, חום־כתום, לוגו בעברית) שמורה ב־
`C:\dev\lulu-v1-backup` ולא נמחקה.

**נגישות ותנועה.** האנימציות נכבות אוטומטית למי שהגדיר
`prefers-reduced-motion`. הטקסט באתר גלוי כברירת מחדל — אם ה־JS לא נטען,
שום דבר לא נשאר מוסתר.
